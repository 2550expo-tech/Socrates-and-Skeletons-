# MindPay Design System

ระบบออกแบบของ MindPay อยู่ในโค้ด: ค่าทั้งหมดอยู่ใน `src/ui/theme.ts` และชิ้นส่วนอยู่ใน `src/ui/components.tsx`, `src/ui/inputs.tsx`, `src/ui/feedback.tsx`
เอกสารนี้สรุปว่าใช้อะไรตอนไหน **กฎข้อแรก: ห้ามหน้าจอไหนคิดสีหรือขนาดเอง** ทุกหน้าใช้ token และ component จากที่นี่ (ข้อยกเว้นอยู่ท้ายเอกสาร)

ทิศทางแบรนด์: Green + Gold (ธีมเริ่มต้น "ป่าทอง") สีเขียวใช้กับโครง สีทองใช้น้อย ๆ กับสิ่งที่สำคัญที่สุดบนหน้า (ยอดเงิน ปุ่มหลัก) ผู้ใช้เลือกธีมสีได้ 9 แบบ (8 ธีม + ฮาโลวีน) แต่ละแบบมีโหมดสว่าง/มืด ทุกหน้าจึงต้องอ่านสีจาก `useTheme()` เท่านั้น

## 1. สี (tokens)

| Token | ใช้กับ | ป่าทอง สว่าง / มืด |
|---|---|---|
| `bg` | พื้นหลังหน้าจอ | `#F2F5F1` / `#0A1410` |
| `surface` | การ์ด, ช่องกรอก, แผ่นด้านล่าง | `#FFFFFF` / `#111E18` |
| `surfaceAlt` | พื้นรอง: กล่องข้อมูล, ราง Segmented, ปุ่ม soft | `#E8EEE8` / `#182820` |
| `line` | เส้นคั่นระหว่างแถว (ตกแต่ง) | `#D6E0D8` / `#22362B` |
| `lineStrong` | ขอบของสิ่งที่กด/กรอกได้: ช่องกรอก, ช่องค้นหา, ราง slider, ปุ่ม ghost (คำนวณให้ได้ ≥ 3:1 บน `bg` และ `surface` ทุกธีม) | คำนวณจาก `line` |
| `ink` | ตัวหนังสือหลัก | `#11231B` / `#E7EFE9` |
| `inkSoft` | ตัวหนังสือรอง, label, คำอธิบาย (ตัวหนังสือที่อ่อนที่สุดที่ใช้ได้) | `#4B5F55` / `#A2B6AA` |
| `inkFaint` | เส้นตกแต่ง, ไอคอนประดับที่ไม่ได้บอกอะไร **ห้ามใช้กับข้อความ, placeholder หรือลูกศร `›`** (ต่ำกว่า 3:1 ในบางธีม) ลูกศรและไอคอนที่บอกว่ากดได้ใช้ `inkSoft` | `#8A9A91` / `#6B8076` |
| `primary` / `onPrimary` | ปุ่มหลัก, สิ่งที่เลือกอยู่, แถบความคืบหน้า / ตัวหนังสือบน primary | `#1F7A52` / `#3FA774` |
| `accent` / `onAccent` | ปุ่มทอง, แท่งกราฟที่เน้น / ตัวหนังสือบน accent | `#C8992A` / `#E2B64A` |
| `accentInk` | ไอคอน ตัวหนังสือ หรือขอบสีทองบนพื้นสว่าง (เข้มพอให้อ่านได้) เช่นขอบการ์ดที่ต้องสนใจ | `#765B19` / `#E2B64A` |
| `accentSoft` | พื้นการ์ด tone="accent", พื้น Badge ทอง | |
| `income`, `good`, `watch`, `critical` | สีที่มีความหมาย: เงินเข้า, ดี, ระวัง, วิกฤต **เหมือนกันทุกธีม** | income `#1F7A52`/`#5CC08E` · good `#26704A`/`#5CC08E` · watch `#9A5200`/`#F0894A` · critical `#A63A26`/`#E07A63` |
| `goodSoft`, `watchSoft`, `criticalSoft` | พื้นอ่อนของสีความหมาย (Badge, กล่องแจ้งเตือน) | |
| `heroTop` → `hero` → `heroDeep` | gradient ของการ์ดยอดเงิน หน้าเรื่องเล่า เวทีน้องกล้า | |
| `heroInk`, `heroInkSoft`, `heroAccent`, `heroIncome`, `heroCritical` | ตัวหนังสือ/ไอคอนบน hero, ตัวเลขเด่นบน hero, เงินเข้าบน hero, เงินไม่พอบน hero (`heroInkSoft`/`heroIncome`/`heroCritical` ถูกยกให้สว่างพอจนอ่านได้ทั้งที่ `heroTop` และ `hero`) | |
| `streak`, `heroStreak` | เปลวไฟ "จดต่อเนื่อง" ตอนจดแล้ววันนี้ บนหน้า / บน hero (≥ 3:1) | |
| `overlay` | ม่านหลัง ConfirmSheet | |

**สีของหมวด** (`src/ui/category.ts`): แต่ละหมวดมีไอคอนและสีเดียวกันทุกธีม (`categoryLook(key, theme)` ให้ `icon`, `tile`, `ink`) ใช้ทั้งแถวรายการ ชิปกรอง โดนัท และคำอธิบายกราฟ คำอธิบายมีไอคอนและชื่อเสมอ สีจึงไม่ใช่สิ่งเดียวที่บอกหมวด เงินเข้าใช้ `income` เสมอ (เป็นความหมาย ไม่ใช่หมวด) TC-95 ตรวจว่าไอคอนอ่านได้บนไทล์ของมัน (≥ 3:1)

ตัวช่วย: `alpha(hex, a)` ทำสีโปร่ง (เช่น pill ของแท็บ `alpha(theme.primary, 0.12)`), `mix(a, b, t)`, `contrast(a, b)`, `readableOn(bg, ...colors)` เลือกสีแรกที่อ่านได้บนพื้นนั้น

**ความอ่านง่าย (บังคับด้วย unit test TC-78):** ทุกคู่สีที่ใช้กับข้อความต้องได้ WCAG AA ≥ 4.5:1 ครบทั้ง 9 ธีม × สว่าง/มืด ได้แก่
`ink`/`inkSoft` บน `bg` และ `surface`, `onPrimary` บน `primary`, `onAccent` บน `accent`, `accentInk` บน `surface` และ `accentSoft`, สีความหมายบนพื้นอ่อนของตัวเองและบน `bg`, `heroInk`/`heroInkSoft`/`heroIncome`/`heroCritical` บน `heroTop` และ `hero`, และ toast
ขอบของสิ่งที่กดได้ (`lineStrong`), ไอคอนหมวดบนไทล์ และเปลวไฟ (`streak`) ต้องได้ ≥ 3:1 (TC-95, WCAG 1.4.11)
ถ้าเพิ่มธีมใหม่ ให้รัน `npm test` แล้ว test จะบอกเองว่าคู่ไหนยังไม่ผ่าน

## 2. ตัวอักษร

- **Noto Serif Thai** (`fonts.serif`, `serifBold`): ตัวเลขเด่น `hero`, `display` และเงินขนาดหัวข้อ (`<Money size="display" | "h1" | "h2">`, tabular digits)
- **Anuphan** (`fonts.sans`, `sansMedium`, `sansSemi`, `sansBold`): ข้อความอื่นทั้งหมด รวมชื่อหน้า (`h1`, `h2`) และเงินขนาดเล็ก (`<Money size="h3" | "body" | "small">` ใช้ `sansSemi`)

| ระดับ | ขนาด / ความสูงบรรทัด | ใช้กับ |
|---|---|---|
| `hero` | 56 / 64 | ตัวเลขเด่นตัวเดียวบนการ์ด hero (จำนวนวันที่เงินพอใช้) เท่ากันทั้งหน้าหลักและหน้าเงินพอถึง |
| `display` | 38 / 52 | ยอดเงินใหญ่ (ใช้จ่ายรวมในหน้าสถิติ, หน้าเรื่องเล่า) |
| `h1` | 24 / 34 | ชื่อหน้าแท็บ |
| `h2` | 20 / 30 | หัวข้อในการ์ด, ยอดสำคัญรอง |
| `h3` | 17 / 26 | ชื่อหน้าแบบ stack, หัวข้อส่วน, ตัวเลขเล็กบน hero |
| `body` | 15 / 24 | เนื้อหา, ปุ่มปกติ |
| `small` | 14 / 22 | คำอธิบาย, ปุ่มเล็ก, ชิป, segmented, toast |
| `micro` | 12 / 18 | badge, ป้ายแท็บ, หมายเหตุ, ป้ายในกราฟ (ภาษาไทยเล็กกว่า 12 วรรณยุกต์จะหาย) |
| `label` | 12 / 18 (= `micro`) ตัว semibold ไม่เว้นระยะตัวอักษร ไม่ใช้ตัวพิมพ์ใหญ่ | ป้ายกำกับ สี `inkSoft` |

ใช้ `<T v="…">` เสมอ ห้ามตั้ง `fontSize` เองโดยไม่มี `lineHeight` เพราะสระบนล่างของภาษาไทยต้องการบรรทัดอย่างน้อยประมาณ 1.4 เท่า
เงินใช้ `<Money satang size sign decimals>` เสมอ ไม่ใช้ `formatBaht` ใน `<T>` สำหรับตัวเลขหลัก (ใน accessibility label หรือประโยคใช้ `formatBaht` ได้)

## 3. ระยะและมุม

- `space`: xs 4 · sm 8 · md 12 · lg 16 · xl 20 · xxl 28 · xxxl 40 (ขอบซ้ายขวาหน้าจอ = `lg`)
- `radius`: sm 8 (ไทล์ไอคอน 28pt, รูปเล็ก) · tile 12 (ไทล์ไอคอน 36–44pt ทุกหน้า) · md 14 (ช่องกรอก, แถวในแผ่นด้านล่าง) · lg 20 (การ์ด กล่องข้อมูล) · xl 28 (การ์ด hero, แผ่นด้านล่าง) · pill (ปุ่ม ชิป badge segmented ช่องค้นหา) วงกลมใช้ครึ่งหนึ่งของขนาด

## 4. Components

| ชิ้นส่วน | ใช้เมื่อ | กฎ |
|---|---|---|
| `Screen` | ทุกหน้า | พื้น `bg`, ขอบ `lg`, เลื่อนช่องที่กำลังพิมพ์ให้พ้นคีย์บอร์ดเอง (ไม่ต้องห่อ KeyboardAvoidingView ซ้ำ) |
| `KeyboardAvoid` | หน้าแบบ stack ที่มีช่องกรอกหรือปุ่มล่าง | ใช้แทน `KeyboardAvoidingView` ทุกที่ ดันเนื้อหาพ้นคีย์บอร์ดทั้ง iOS และ Android (Android แบบ edge-to-edge ไม่ย่อหน้าต่างให้เอง) |
| `Card` | กลุ่มเนื้อหา | `surface` ไม่มีเส้นขอบ + radius lg + padding lg (การ์ดภารกิจ สกิน และรูปสลิปก็ไม่มีเส้นขอบ); `tone="alt"` พื้นรอง, `tone="accent"` พื้นทองอ่อน; **การ์ดที่ต้องสนใจ** (สลิปรอยืนยัน, ของใหม่, ทำสำเร็จ) = `borderColor: accentInk, borderWidth: 1.5` |
| `Button` | การกระทำ | `primary` (1 ปุ่มหลักต่อหน้า), `gold` (การกระทำเด่นที่ให้รางวัล), `soft`, `ghost`, `danger`, `onDark` (บน hero); `small` สำหรับปุ่มรอง พื้นที่แตะสูงถึง 44pt |
| `IconButton` | ปุ่มไอคอน | 42pt + hitSlop 8 ต้องมี `label` เสมอ; `disabled` = จาง กดไม่ได้ และบอก screen reader |
| `Segmented` | สลับมุมมอง 2–4 แบบ | pill ขาวมีเงา (สว่าง) / pill สีธีมโปร่ง (มืด) |
| `Chip` | ตัวเลือกหลายอัน, คำถามด่วน | เลือกแล้ว = ขอบ `primary` + พื้น `alpha(primary)` **สิ่งที่เลือกอยู่ทุกแบบใช้ `primary`** (สกิน ไอคอนกระปุก วันในปฏิทิน แท็บ) ไม่ใช้ทอง |
| `Toggle` | เปิด/ปิดการตั้งค่า | ราง `primary` ตอนเปิด, `inkFaint` ตอนปิด, ปุ่มกลมสีขาวทุกแพลตฟอร์ม; ต้องมี `label` |
| `Badge` | สถานะสั้น ๆ | `neutral`, `good`, `watch`, `critical`, `gold`; บน hero ใช้ `onDark` |
| `Field` / `inputBox()` + `inputText()` | ช่องกรอกทุกชนิด รวมช่องรหัส OTP, ช่องค้นหา (radius pill) และปุ่มเลือกวัน/เวลาบน Android | `surface`, ขอบ 1.5 `lineStrong` → `primary` ตอนพิมพ์ → `critical` ตอนผิด, radius md; บนเว็บตัวหนังสือ 16 เพื่อไม่ให้ iPhone ซูมหน้า |
| `Slider` | เลื่อนค่า (หน้าเงินพอถึง) | ราง `lineStrong`, ส่วนที่เลื่อนแล้วและปุ่ม `primary` ขอบ `surface`; บนเว็บมีวง `ink` ตอนโฟกัสและกดลูกศรได้ |
| `StackHeader` | หัวทุกหน้าแบบ stack (รวมสแกนสลิปและพูดจด) | ปุ่มกลับ/ปิด + ชื่อ `h3` (เป็น heading) + ช่องขวา |
| `SectionHead` | หัวข้อส่วนบนหน้า (นอกการ์ด) | `h3` heading + ข้อความหรือปุ่มทางขวา (`right`) หรือลิงก์ "ดูทั้งหมด ›" สี `ink` สูง 44pt; หัวข้อในการ์ดใช้ `<T v="h3">` ได้ |
| `TxRow` | แถวรายการเงิน | อยู่บนการ์ด `surface` ขอบซ้ายขวา `lg`, เส้นคั่นเริ่มที่ `TX_DIVIDER_INSET` (หลังไทล์) เหมือนกันทุกหน้า |
| แผ่นด้านล่าง (`add.tsx`, `ConfirmSheet`) | เลือกวิธีจด, ยืนยัน | `surface` มุมบน xl, ขีดจับ `lineStrong`, ม่าน `overlay`, ปิดได้ด้วย ✕ แตะม่าน Esc ปุ่มย้อน |
| `EmptyState` | ไม่มีข้อมูล | ไอคอนหรือน้องกล้า + หัวข้อ + คำอธิบาย + ปุ่ม soft |
| `useToast()` | ยืนยันผลการกระทำ | พื้น `ink`, ตัวหนังสือ `bg` ขนาด `small`; ผิดพลาด = `critical`; ประกาศให้ screen reader (iOS ด้วย) |
| `ConfirmSheet` | ก่อนการกระทำที่ย้อนไม่ได้ | ปุ่มยืนยัน `danger` ถ้าเป็นการลบ |
| `BuddySays` | น้องกล้าพูดสั้น ๆ | ฟองคำพูด `surface` ขอบ hairline (ฟองคำพูดเป็นข้อยกเว้นเดียวที่มีเส้นขอบ) |
| กราฟ (`charts.tsx`) | ยอดรายวัน, หมวด | แท่งปกติ `primary` จาง, แท่งที่เน้น (วันนี้) `accent` เต็ม ต่างกันทั้งสีและความสว่าง; ป้ายตัวเลข 12pt; หมวดใช้สีของหมวด |

**ตอนกด:** ทุกอย่างที่กดได้ต้องเปลี่ยนให้เห็น การ์ดหรือแถวที่เป็นพื้น `surface` ทั้งก้อน (แถวตั้งค่า, การ์ดแจ้งเตือน, ตั้งงบ, รูปสลิป, ปุ่มเลือกวัน) เปลี่ยนพื้นเป็น `surfaceAlt`; แถวในรายการ (`TxRow`, หัวข้อข่าวเก่า) จางลง (opacity 0.6–0.7); ปุ่มและชิปยุบตัวเล็กน้อย (`usePressSpring`)

**หัวหน้าจอ**
- แท็บ (หน้าหลัก, รายการ, สถิติ, โค้ช): `h1` ชิดซ้าย, ของตกแต่ง/ปุ่มทางขวา, ห่างขอบบน `sm` ทุกแท็บ (ชื่อจึงไม่กระโดดตอนสลับแท็บ)
- หน้าแบบ stack: `StackHeader` เสมอ (ปุ่มกลับ/ปิด + ชื่อ `h3` ตรงกลาง + ช่องขวา 42pt)

**พื้นที่แตะ:** การกระทำทุกอย่างต้องแตะได้อย่างน้อย 44pt (ใช้ `minHeight` หรือ `hitSlop` แนวตั้ง เพื่อไม่ให้ปุ่มที่อยู่ติดกันแย่งพื้นที่แตะกัน)

## 5. การเคลื่อนไหว

ใช้ตัวช่วยใน `src/ui/effects.tsx` และ `motion.ts` เท่านั้น ทุกเอฟเฟกต์ขยับไม่กี่รอบแล้วหยุดเอง (ประหยัดแบต) ใช้ native driver และหยุดทั้งหมดเมื่อเปิด "ลดการเคลื่อนไหว"
(ทดสอบใน E2E: หน้าหลักนิ่งภายใน 9 วินาที)

## 6. ธีมเทศกาล

ธีมที่มี `festival: true` (ฮาโลวีน) ตกแต่งได้เฉพาะส่วนหัว, การ์ด hero และเวทีน้องกล้า (`src/ui/halloween.tsx`) ห้ามวางทับตัวเลขเงิน ผู้ใช้ต้องปิดได้เสมอ

## 7. ข้อยกเว้น (สีตายตัวที่อนุญาต)

- ภาพวาด SVG: น้องกล้า (`ui/kla/art.tsx`), ต้นไม้เงิน (`ui/art.tsx`), เหรียญ (`Medal.tsx`), โหลออม (`Jar.tsx`), ผี/ค้างคาว/ฟักทอง (`halloween.tsx`), ไอคอนแอป
- ทองของเหรียญ/พลุ (`palette.gold*`) ซึ่งเป็นสีของวัตถุ ไม่ใช่สีของ UI
- หน้าเรื่องเล่าสรุปเดือน (`recap.tsx`) ที่แต่ละหน้ามี gradient ของตัวเอง และไอคอนฟีเจอร์ในหน้า "มีอะไรใหม่"
- ปฏิทินการใช้จ่าย (`SpendCalendar.tsx`) ใช้ไล่สีที่ตรวจความต่างสีแล้ว
- แอนิเมชันเปิดแอปบนมือถือใช้สีป่าทองให้ต่อจาก splash ของระบบ (บนเว็บใช้สีธีม)

## 8. เช็กลิสต์ก่อนเพิ่มหน้าจอใหม่

1. ไม่มีรหัสสี `#…` หรือ `rgba(…)` ในหน้าจอ (ยกเว้นข้อ 7) ใช้ token หรือ `alpha()` บน hero ใช้ `hero*` เท่านั้น
2. ตัวหนังสือใช้ `<T>` และเงินใช้ `<Money>`
3. ปุ่ม ชิป ช่องกรอก และการ์ดมาจาก component ไม่สร้างใหม่ด้วย `Pressable` + style เอง
4. ลองเปิดหน้านั้นใน 2–3 ธีม ทั้งสว่างและมืด (`node scripts/theme-shot.mjs <path> 0 <ชื่อไฟล์> dark <ธีม>` ภาพอยู่ใน `theme-shots/`)
5. `npm test` (รวม TC-78 ความอ่านง่าย), `npx tsc --noEmit`, `npx expo lint`, `npm run e2e:web`
